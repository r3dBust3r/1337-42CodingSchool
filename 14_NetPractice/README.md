## Description

NetPractice is a general practical exercise designed to introduce the basics of computer networking. The goal of this project is to configure small-scale simulated networks to make them function properly. Through this activity, participants learn how to configure IP addresses, connect devices through a router, and understand the role of a gateway within a network. You are required to solve 10 levels of networking problems by adjusting the available configurations on a non-functioning network diagram.

## Instructions

To launch and use the training interface for this project, follow these steps:

* download net_practice.1.9.tgz from [https://cdn.intra.42.fr/document/document/51760/net_practice.1.9.tgz](https://cdn.intra.42.fr/document/document/51760/net_practice.1.9.tgz)
* extract it
* cd net_practice
* Run the shell script to launch the local web server and open the interface in your preferred web browser: `./run.sh`
