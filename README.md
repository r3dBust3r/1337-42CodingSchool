# 1337 / 42 Coding School Projects

This repository collects my 1337 / 42 coding school work across systems programming, C libraries, shell tooling, Python projects, and concurrency exercises. It includes both completed projects and supporting concept notes I wrote while learning the curriculum.

## Repository Overview

The main project folders are organized by subject:

- `01_Libft` - a custom C standard-library replacement with string, memory, conversion, and linked-list helpers.
- `02_Printf` - a `printf`-style formatter implemented in C.
- `03_Get_Next_Line` - a line-by-line file reader with mandatory and bonus versions.
- `04_Born2beRoot` - a Debian virtual machine hardening project covering partitions, users, services, firewall rules, and sudo policies.
- `05_Push_Swap` - a stack-sorting project that generates efficient move sequences and includes a checker bonus.
- `06_Python_Modules` - a sequence of Python module exercises from the curriculum.
- `07_A_Maze_ing` - a maze / pathfinding project.
- `08_Pipex` - a shell pipeline reproduction project built around pipes, forks, and process execution.
- `09_Call_Me_Maybe` - a constrained function-calling pipeline for structured JSON output from natural language prompts.
- `10_Fly_in` - a drone routing and visualization project with parsing, graph search, simulation, and rendering.
- `11_Codexion` - a multithreaded concurrency simulation inspired by the dining philosophers problem.

## What This Repository Shows

Across these projects, the repository reflects a progression through:

- Low-level C programming
- Memory management and custom data structures
- UNIX process control and shell behavior
- System administration fundamentals
- Algorithm design and optimization
- Advanced python application design
- Multithreading and synchronization
